# Provider benchmarks

No live paid benchmark was run without owner keys and consent. The repository
includes deterministic contract validation for request shape, authentication,
endpoint policy, routing, budgets, exports, and failure behavior.

When credentials are available, benchmark per provider/model with a fixed,
non-sensitive fixture set. Record timestamp, official catalog revision, latency
percentiles, first-token latency, success/error rates, structured-output
validity, tool-call validity, usage, and provider-reported actual cost. Never
rank estimated cost as actual, never publish secret headers or prompts, and
expire results when the catalog or pricing changes.
